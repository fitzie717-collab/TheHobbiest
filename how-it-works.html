Good to know

A few things worth noting.

Class Minimums

Every class requires 10–12 confirmed members to run. We schedule the date once that threshold is reached — so submitting an interest form is the fastest way to make a class happen.

All Materials Included

Every single-session class price includes all materials, tools, and supplies for that session. Nothing to bring except yourself and a willingness to try something new.

Member Credits

Studio membership dues ($45/month) apply 100% as credits toward any class. Starting in 2027, unused monthly credits expire at month-end, so use them that month.
